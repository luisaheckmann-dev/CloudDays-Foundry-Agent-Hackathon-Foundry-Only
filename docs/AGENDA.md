# 210 Minutes - An End-to-End Browser Workshop

[Home](../README.md) | [Step-by-step guide](PORTAL-GUIDE.md) | [Instructor](INSTRUCTOR.md)

**Audience:** Azure/AI beginners with basic browser skills. No Python,
terminal, or machine learning training required. One person per account
and project; discussions can take place in teams of two or three.
No shared passwords or shared administrator account.

Test sign-in and model access before the event whenever possible.
Lab 0's 15 minutes are not enough for new quota, authorization, or
network exceptions. Registered participants can optionally complete their
first sign-in and MFA beforehand; personal email addresses are not technically
required when workshop accounts are allocated separately.

## Learning Objectives

You can create a prompt agent, save its configuration, check an actual
source, interpret conflicting documents, distinguish an order recommendation
from an executed order, and measure improvement using the same questions.

## Definition of Done

Your own agent artifact exists in your own project. Four sources are
indexed or preconfigured by the instructor; at least one answer has a
relevant retrieval source that you can open. The six core tests E01,
E03, E05, E06, E07, and E09 have each been scored in fresh chats.
There are no claims of a live inventory query, an executed order, or
technical approval. The [rubric and hard failures](EVALUATION.md) apply.

Pasting context without File Search or watching an instructor demonstration
does **not** pass your individual cloud/retrieval evidence requirement.
Clearly mark any blocker in your submission.
